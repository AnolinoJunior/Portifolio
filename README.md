# Portfólio de Anolino Junior

Site estático em português do Brasil. Abra `index.html` no navegador ou execute `python -m http.server 8000` nesta pasta e acesse `http://localhost:8000`.

Não há dependências para instalar nem etapa de compilação.

## Foto

A foto original fornecida está preservada em `assets/foto3x4.jpeg`. O site usa a versão com brilho suavizado em `assets/foto3x4-retocada.png`. O CSS usa `object-fit: cover` e `object-position` para preservar a proporção e enquadrar o rosto.

## Créditos e origem

Implementação original inspirada na linguagem visual geral do [Portfolio_Giu, de Giullia Lazaro](https://github.com/atchiullia/Portfolio_Giu).
